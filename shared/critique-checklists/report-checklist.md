# Report Checklist

Used by the **report critic** to review Phase 6 final output before delivery.

Focus: writing quality, structural completeness, and faithful representation of evidence.
Evaluate against this checklist. Return PASS, REVISE, or FAIL.
Cite the exact checklist item number that failed.

---

## R1: Structural completeness

- [ ] R1.1 — The correct template for the mode was used (full / quick / thesis-test / data-first / literature)
- [ ] R1.2 — All required sections are present (no section skipped without documented reason)
- [ ] R1.3 — The executive summary stands alone (a reader of only the summary understands: finding, evidence quality, main caveat)
- [ ] R1.4 — Data sources are listed with access dates

## R2: Faithful representation

- [ ] R2.1 — The executive summary matches the detailed findings (no inconsistency)
- [ ] R2.2 — Confidence score stated in the report matches the output of confidence-scorer
- [ ] R2.3 — Caveats from the data quality audit are present in the final report
- [ ] R2.4 — Skeptic challenges that were UNRESOLVED are present in the report (not dropped)
- [ ] R2.5 — Null results are documented, not omitted

## R3: Writing quality — AI filler

Scan for and flag any of the following. Each found is a REVISE:

- [ ] R3.1 — "it's worth noting" — must not appear
- [ ] R3.2 — "importantly" as a sentence opener — must not appear
- [ ] R3.3 — "certainly" / "absolutely" as qualifiers — must not appear
- [ ] R3.4 — "delve" in any form — must not appear
- [ ] R3.5 — "in today's [X] landscape" — must not appear
- [ ] R3.6 — "fascinating" / "exciting" / "groundbreaking" (not in a direct quote) — must not appear
- [ ] R3.7 — "this report will..." or "in this analysis we will..." — must not appear
- [ ] R3.8 — Three-part list ending "and finally" — must not appear

## R4: Writing quality — structure

- [ ] R4.1 — Findings are stated first, methodology second (not buried after 3 paragraphs of method description)
- [ ] R4.2 — Statistics are embedded in prose with context (not raw table outputs pasted in)
- [ ] R4.3 — No em dashes used as clause connectors
- [ ] R4.4 — Effect sizes and p-values use correct precision (2-3 significant figures in prose)
- [ ] R4.5 — All numbers specify timeframe ("annualised Sharpe of 1.4 over 2015-2024", not just "Sharpe of 1.4")

## R5: Proportionality

- [ ] R5.1 — Length is proportionate to mode (quick brief: 1-2 pages; full report: up to 5 pages; not inflated)
- [ ] R5.2 — No section is repeated verbatim from another section
- [ ] R5.3 — Methodology section does not exceed findings section in length
