# Logic Checklist

Used by the **logic critic** to review Phase 3 reasoning and Phase 4 synthesis.

Focus: internal consistency, causal language, and argument structure.
Evaluate against this checklist. Return PASS, REVISE, or FAIL.
Cite the exact checklist item number that failed.

---

## L1: Hypothesis alignment

- [ ] L1.1 — The analysis conducted matches the hypothesis stated in the research brief
- [ ] L1.2 — The success criteria were evaluated (pass/fail stated, not skipped)
- [ ] L1.3 — The conclusion follows from the results (not from the hypothesis alone)
- [ ] L1.4 — Negative results are reported, not omitted

## L2: Causal language

- [ ] L2.1 — Causal language ("causes", "drives", "leads to") is used only where a causal method was employed (Granger, DiD, IV, RDD)
- [ ] L2.2 — Associative language ("correlated with", "associated with", "predictive of") is used for observational findings
- [ ] L2.3 — No finding is described as "proving" causation from observational data alone
- [ ] L2.4 — Alternative explanations for each finding are acknowledged, even briefly

## L3: Scope of claims

- [ ] L3.1 — Claims are scoped to the sample studied (no generalisation to populations not in the data)
- [ ] L3.2 — Time period is specified for every claim (no timeless assertions from time-bounded data)
- [ ] L3.3 — Claims do not exceed what the effect size and statistical power support
- [ ] L3.4 — Marginal findings (borderline significance, small effect) are not presented as strong evidence

## L4: Consistency

- [ ] L4.1 — Results are internally consistent (no contradictions between sections)
- [ ] L4.2 — Conclusions in the executive summary match the detailed findings
- [ ] L4.3 — Confidence score matches the evidence quality (not inflated or deflated by reasoning outside the rubric)
- [ ] L4.4 — Caveats stated in the data quality report are carried through to the conclusions

## L5: Data snooping

- [ ] L5.1 — All tests run are documented (not just the ones that produced significant results)
- [ ] L5.2 — If multiple specifications were tested, the primary result was pre-specified or a correction was applied
- [ ] L5.3 — The result is not described as "finding the best specification" without correction
